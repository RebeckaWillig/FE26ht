# Receptsajten

Receptsajten is a recipe website developed as part of a frontend development course. The project is an exercise in building accessible, responsive, and well-structured web pages using HTML and CSS.

A key focus is writing clean, maintainable code through semantic HTML, consistent CSS practices, reusable design tokens, and flexible layouts. The project also explores accessibility and responsive design, with an emphasis on making conscious design and coding decisions that make the code easier to read, understand, and build upon.

## Features

- **Recipe overview:** A homepage presenting recipes in a clear and accessible layout.
- **Recipe details:** Individual recipe pages displaying ingredients, instructions, and other relevant information.
- **Recipe submission:** A form allowing users to enter and submit their own recipe details.[^1]
- **Responsive layout:** Flexible layouts designed to work across different screen sizes.
- **Accessible navigation:** Semantic page structure, descriptive links, and skip navigation to improve usability.

[^1]: The form is frontend-only and has no backend functionality, so submitted recipes are not stored or processed.

## Code Practices & Learning Objectives

The project focuses on developing good frontend development practices, including:

- **Semantic HTML:** Using appropriate HTML elements to create meaningful document structure.
- **Clean code:** Writing readable, consistent, and maintainable code.
- **CSS organisation:** Structuring stylesheets logically and avoiding unnecessary repetition.
- **Reusable design tokens:** Using CSS custom properties to maintain consistent colours, spacing, and other design values.
- **Responsive design:** Using flexible layouts and media queries to accommodate different screen sizes.
- **Accessibility:** Exploring WCAG guidelines and accessibility best practices, with a focus on keyboard navigation, screen reader compatibility, and semantic HTML. Using tools such as WAVE to evaluate accessibility and identify potential improvements.
